<h1>Приложение калькулятор</h1>
<h3>Реализованный функционал:</h3>
<ul>
<li>Считывается первое число</li>
<li>Считывается действие (+, -, /, *)</li>
<li>Считывается второе число</li>
<li>Вычисление значения и вывод результата</li>
<li>Обработка деления на 0 с выводом сообщения об ошибке</li>
<li>Реализована бесконечная работа калькулятора с возможностью выхода (команда !)</li>
<li>Сброс результата (команда #)</li>
<li>Обработка ввода неподдерживаемой операции</li>
<li>Защита от ввода символа вместо числа</li>
<li>Отображение целого результата без дробной части</li>
</ul>
